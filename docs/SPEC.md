# אפיון: מגש מערכת חלופי למחשב קיוסק

> שם התוכנה: **Virtual System Bar**

## 1. רקע ומטרה

במחשב שרץ במצב קיוסק שורת המשימות של Windows מוסתרת. לכן אין למשתמש גישה לרמקול, ל-Wi-Fi, ל-Bluetooth, לשפת המקלדת וכו'.
התוכנה מציגה פס סטטוס קטן ועצמאי שמחליף את המגש של Windows. **כל ההגדרות מתבצעות בתוך התוכנה עצמה**, בלי שום מעבר להגדרות של Windows. כך אי אפשר לעקוף את החסימה או לשנות הגדרות לא רצויות.

## 2. הפס (המסך הראשי)

פס אופקי קטן, תמיד מעל כל החלונות (Topmost), שמציג את הרכיבים הבאים משמאל לימין:

| # | רכיב | תצוגה בפס | מה קורה בלחיצה |
|---|------|-----------|----------------|
| 1 | שעה ותאריך | `16:00` / `28/09/2026` | אין פעולה (אופציה: תאריך עברי ב-tooltip) |
| 2 | רמקול | אייקון לפי עוצמה / השתקה | חלונית עוצמה (סעיף 3.1) |
| 3 | Wi-Fi | אייקון לפי עוצמת אות / מנותק | חלונית רשתות (סעיף 3.2) |
| 4 | שפת מקלדת | `עבר` / `ENG` | מעבר לשפה הבאה, או רשימה (סעיף 3.3) |
| 5 | מקלדת מגע | אייקון מקלדת | פתיחה וסגירה של מקלדת המסך |
| 6 | Bluetooth | אייקון דולק / כבוי | חלונית Bluetooth (סעיף 3.4) |
| 7 | הוצאת USB | אייקון, מוצג רק כשמחובר כונן נשלף | רשימת כוננים להוצאה בטוחה (סעיף 3.5) |
| 8 | סוללה (אופציונלי) | אחוז טעינה, רק במחשב נייד | אין פעולה |
| 9 | ⚙ גלגל שיניים | אייקון קטן | בקשת סיסמה, ואז מסך ניהול (סעיף 4) |

**מיקום:** ברירת המחדל היא הפינה הימנית התחתונה. המנהל יכול לשנות את הפינה בהגדרות.
**גודל:** קטן, בגובה של שורת המשימות הרגילה (בערך 40px), וניתן להגדלה למסכי מגע.
**עיצוב:** בהיר, דומה למגש של Windows 10/11, בעברית, מימין לשמאל.

## 3. חלוניות פעולה (נפתחות מעל הפס)

כל החלוניות נפתחות בתוך התוכנה ונסגרות בלחיצה מחוץ להן. **אין בשום חלונית קישור להגדרות Windows** ("הגדרות רשת נוספות", "פתח הגדרות" וכו').

### 3.1 שמע
- פס עוצמה (0–100) וכפתור השתקה.
- אופציה (ניתן לכבות בהגדרות): בחירת התקן פלט (רמקולים / אוזניות / Bluetooth).
- אופציה: תקרת עוצמה מקסימלית שהמנהל קובע.

### 3.2 Wi-Fi
- מתג הפעלה וכיבוי של Wi-Fi.
- רשימת רשתות זמינות עם עוצמת אות ומנעול לרשתות מוגנות.
- התחברות לרשת והזנת סיסמה בחלון של התוכנה. תיבת הסיסמה עובדת עם מקלדת המגע.
- ניתוק מהרשת הנוכחית.
- **אופציה חשובה למנהל:** רשימה לבנה של רשתות מותרות. רק הן מוצגות, ורשתות אחרות מוסתרות לגמרי.

### 3.3 שפת מקלדת
- לחיצה מחליפה לשפה הבאה מתוך השפות שמותקנות ב-Windows.
- לחיצה ארוכה או לחיצה ימנית פותחת רשימה לבחירה.

### 3.4 Bluetooth
- מתג הפעלה וכיבוי.
- רשימת התקנים מצומדים עם כפתור התחבר או נתק.
- חיפוש התקנים חדשים וצימוד. **המנהל יכול לנעול את האפשרות הזו**, כך שיהיה רק חיבור להתקנים שכבר צומדו.

### 3.5 הוצאת USB בטוחה
- רשימת כוננים נשלפים שמחוברים כרגע, עם שם ואות כונן.
- כפתור "הוצא" ליד כל כונן, והודעה "ניתן לנתק" או "הכונן בשימוש".

### 3.6 מקלדת מגע
- פתיחה וסגירה של מקלדת המגע של Windows (TabTip / OSK). המקלדת עצמה לא פותחת גישה להגדרות.

## 4. מסך ניהול (גלגל שיניים)

- **כניסה בסיסמה בלבד.** בהפעלה הראשונה מוגדרת סיסמה, והיא נשמרת כגיבוב (hash) ולא כטקסט גלוי.
- אחרי 5 ניסיונות שגויים יש נעילה זמנית של דקה.
- הגדרות:
  - **מה מוצג בפס:** תיבת סימון לכל רכיב מסעיף 2. דוגמה מהמבקש: להציג רק רמקול ו-Bluetooth בלי Wi-Fi.
  - **הגבלות בתוך רכיבים:** רשימה לבנה של רשתות Wi-Fi, איסור צימוד Bluetooth חדש, תקרת עוצמה, איסור כיבוי Wi-Fi או Bluetooth.
  - **מיקום וגודל הפס.**
  - **החלפת סיסמה.**
  - **יציאה מהתוכנה**, מותרת רק מכאן.
- ההגדרות נשמרות בקובץ בתיקייה מוגנת (ProgramData), כך שמשתמש רגיל לא יכול לערוך אותו.

## 5. אבטחה ומניעת עקיפה

1. **אף פעולה לא פותחת** את ms-settings:, את לוח הבקרה, את ncpa.cpl, את מנהל ההתקנים וכו'. כל הפעולות מתבצעות ישירות מול ה-API של Windows.
2. אין תפריט קליק ימני של המערכת ואין קישורים חיצוניים.
3. אי אפשר לסגור את התוכנה בלי סיסמה. Alt+F4 לא עובד על הפס, והיא לא מופיעה בחלון המשימות.
4. **עלייה אוטומטית** עם כניסת המשתמש, דרך Task Scheduler או ההגדרה של הקיוסק.
5. **הפעלה מחדש אוטומטית** אם התהליך נסגר או קורס (watchdog).
6. כל הודעת שגיאה מוצגת בתוך התוכנה, ולא דרך חלון של Windows שיש בו קישורים.

## 6. דרישות טכניות

- **מערכת:** Windows 10 ו-Windows 11 (64 סיביות).
- **קובץ:** EXE יחיד, בלי התקנה ובלי תלויות חיצוניות.
- **הרשאות:** ההפעלה השוטפת במשתמש רגיל. פעולות שדורשות הרשאות מנהל (הפעלה וכיבוי של מתאמים) מתבצעות דרך שירות קטן שמותקן פעם אחת, או שמוותרים עליהן. לבדוק מול מצב הקיוסק בפועל.
- **שפה:** עברית, מימין לשמאל.

## 7. פתוח / לברר עם המבקש

1. ~~שם התוכנה~~: נקבע, "Virtual System Bar".
2. **תמונה 2 בצ'אט** עדיין בבדיקה של נטפרי. כנראה חלונית ההגדרות המהירות של Windows. אם יש בה רכיבים נוספים, להוסיף אותם.
3. **סוג הקיוסק:** Assigned Access (אפליקציה אחת), Shell Launcher או תוכנת קיוסק אחרת. זה קובע אם בכלל אפשר להריץ לצידו תוכנה נוספת, ואיך.
