# Virtual System Bar

פס סטטוס קטן שמחליף את אזור ההתראות (המגש) של Windows במחשבי קיוסק.
במצב קיוסק שורת המשימות מוסתרת, ולכן אין גישה לרמקול, ל-Wi-Fi, ל-Bluetooth ולשפת המקלדת. התוכנה מחזירה את כל אלה
**בלי לפתוח אף פעם את ההגדרות של Windows**, כך שאי אפשר לעקוף דרכה את החסימה.

**הורדה:** [VirtualSystemBar.exe](https://github.com/tsoolgee/virtual-system-bar/releases/latest/download/VirtualSystemBar.exe) (קובץ יחיד ונייד, בלי התקנה: מורידים ומפעילים)

![הפס](docs/bar.png)

## מה יש בפס

| רכיב | מה אפשר לעשות |
|------|---------------|
| שעה ותאריך | במעבר עכבר מוצגים היום בשבוע והתאריך העברי |
| רמקול | עוצמה, השתקה, בחירת התקן פלט (רמקולים / אוזניות) |
| Wi-Fi | הדלקה וכיבוי, רשימת רשתות, התחברות עם סיסמה, התנתקות |
| שפת מקלדת | לחיצה מחליפה לשפה הבאה, ולחיצה ימנית פותחת רשימה של כל השפות |
| מקלדת מגע | פתיחה וסגירה של מקלדת המגע של Windows |
| Bluetooth | הדלקה וכיבוי, התקנים מצומדים, התחברות והתנתקות, צימוד התקן חדש |
| הוצאת USB | מופיע רק כשמחובר כונן נשלף. מוציא אותו בבטחה, או מודיע שהוא בשימוש |
| סוללה | מופיע רק במחשב נייד |
| ⚙ | הגדרות מנהל, מוגנות בסיסמה |
| ✕ | סגירת התוכנה. המנהל קובע אם ה-X מוצג, ואם הסגירה דורשת סיסמה או פתוחה לכל משתמש |

## הגדרות מנהל (⚙)

בלחיצה הראשונה על ⚙ בוחרים סיסמת מנהל. אחרי 5 ניסיונות שגויים ההגדרות ננעלות לדקה.

- **מה מוצג בפס**: כל רכיב אפשר להסתיר. לדוגמה, להשאיר רק רמקול ו-Bluetooth, בלי Wi-Fi.
- **כפתור X**: אפשר להסתיר אותו. אם הוא מוצג, המנהל קובע אם הסגירה דורשת סיסמה (מתאים לקיוסק), או שכל משתמש יכול לסגור, למשל כשהפס מסתיר לו משהו.
- **שמע**: תקרת עוצמה, והאם מותר להחליף התקן פלט.
- **Wi-Fi**: האם מותר להדליק ולכבות, האם מותר להתנתק, **ורשימה לבנה**: רק הרשתות שברשימה מוצגות.
- **Bluetooth**: האם מותר להדליק ולכבות, להתחבר ולהתנתק, לצמד התקנים חדשים ולהסיר התקנים.
- **תצוגה**: באיזו פינה של המסך הפס יושב, וגודל (100% עד 200%). כששורת המשימות של Windows מוצגת, הפס יושב מעליה (אפשר לכבות), כך שמקש Windows ותפריט התחל לא מסתירים אותו. גם שורת משימות שמוסתרת אוטומטית: כשהיא קופצת, הפס זז מעליה.
- **מסך הנעילה**: הסתרת כפתור הרשת (Wi-Fi) במסך הנעילה והכניסה של Windows, כך שאי אפשר לשנות את חיבור הרשת בלי להיכנס למשתמש. זו מדיניות של Windows שחלה על כל המשתמשים במחשב, ובשמירה Windows מבקש הרשאות מנהל.
- **מערכת**: הפעלה אוטומטית עם כניסת המשתמש, "שומר" שמפעיל את התוכנה מחדש אם סוגרים אותה, החלפת סיסמה, ויציאה מהתוכנה.

ההגדרות נשמרות ב-`C:\ProgramData\VirtualSystemBar\config.json`. אם שמים קובץ `config.json` ליד ה-EXE, התוכנה עובדת במצב נייד ומשתמשת בו.

## הגנה מפני עקיפה

- אין בתוכנה אף קישור להגדרות Windows, ללוח הבקרה או למנהל ההתקנים. כל הפעולות מתבצעות ישירות מול Windows, מתוך התוכנה.
- מקלדת המגע נפתחת רק דרך TabTip. התוכנה לא משתמשת ב-osk.exe, כי מסך האפשרויות שלו מוביל ללוח הבקרה.
- הפס לא מופיע בשורת המשימות וב-Alt+Tab, ו-Alt+F4 לא סוגר אותו. יוצאים מהתוכנה ממסך הניהול, או בכפתור X אם המנהל הפעיל אותו.
- **השומר**: עותק שני של התוכנה רץ ברקע. אם סוגרים את הפס ממנהל המשימות או שהוא קורס, השומר מפעיל אותו מחדש. אם סוגרים את השומר, הפס מפעיל אותו מחדש.
- הפס אף פעם לא לוקח את הפוקוס, כך שהקלדה ממשיכה לעבור לתוכנת הקיוסק.

## הערות

- **מסך הנעילה**: הפס עצמו לא מופיע במסך הנעילה. Windows מציג את מסך הנעילה על שולחן עבודה נפרד ומוגן, ותוכנה רגילה לא יכולה לצייר עליו. מה שאפשר הוא להסתיר שם את כפתור הרשת (ראו למעלה).

- **Windows 11 (גרסה 24H2 ומעלה)**: כדי לסרוק רשתות Wi-Fi, Windows דורש שתהיה מופעלת "גישה למיקום" לאפליקציות שולחן עבודה. זה מופעל בהגדרות הפרטיות של Windows, פעם אחת, על ידי המנהל.
- **התחברות והתנתקות ב-Bluetooth** עובדות דרך הפעלה וכיבוי של שירותי ההתקן (אודיו, מקלדת או עכבר). במחשבים מסוימים הפעולה הזו דורשת הרשאות מנהל, ואז מוצגת הודעה.
- מקלדת המגע של Windows 11 כוללת כפתור הגדרות משלה. אם זה מפריע, מסתירים את הרכיב בהגדרות, או חוסמים את ms-settings במדיניות של הקיוסק.
- **הפעלה אוטומטית** נרשמת למשתמש שמריץ את ההגדרות. לכן צריך לסמן אותה כשמחוברים כמשתמש הקיוסק.

## בנייה

```
dotnet build -c Release -o dist
```

נדרש .NET SDK 8. היעד הוא .NET Framework 4.8, שמותקן בכל Windows 10 ו-11. יוצא קובץ EXE יחיד.
האפיון המלא נמצא ב-[docs/SPEC.md](docs/SPEC.md).
